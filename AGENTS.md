# Agent Instructions

Follow these guidelines when contributing to this repository.

- Use four spaces for indentation in JavaScript and CSS files.
- Keep line length under 80 characters when possible.
- After modifying source files, run `npm run build` to regenerate `dist/bundle.js`. Do not commit the compiled bundle or `node_modules`.
- No automated tests are defined. Check the game manually in a browser after building.
- Commit messages should be brief but descriptive.
